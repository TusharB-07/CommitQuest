    FAQ

    Is my GitHub data safe?+

    Yes. We only request public data via GitHub's read-only API, we never ask for a token or password, and nothing is stored on any server — all state lives in your browser's localStorage.

    I have 3 commits total. Is this useless for me?+

    That's exactly who it's for. Level 1→2 takes one commit. The whole design goal is making the next small step feel rewarding.

    Why does loading a real user sometimes fail?+

    GitHub's unauthenticated API is rate-limited to 60 requests/hour per IP. If you hit the cap, the app gracefully falls back to the demo dataset and tells you why.
